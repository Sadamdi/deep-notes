# AI assistance disclosure

STACK 2026 requires material AI assistance to be disclosed with the tool and its role. Keep this table current.

| Area | Tool | Role | Human review |
|---|---|---|---|
| Product feature | Gemini API | answers questions from retrieved passages, generates quizzes, creates embeddings | citations are validated against retrieved chunks; ungrounded answers are refused |
| Development | AI coding assistants | drafting code, tests, documentation and project scaffolding | all changes are reviewed through pull requests; the team understands and owns the code |

Update the "Development" row with the specific tools and what they were used for as the project progresses. Do not hide material use.
